    搜索怎么写

    和 rg 的写法一样：pattern 是逐行匹配文件内容的正则，开关与 rg 参数一一对应。首页和 Agent 的 search 工具参数相同

    按场景选择调用

    以下是工具参数。请替换 group/name 和文件路径；后续读取使用搜索返回的 commit

    01 · 判断相关性

    search
{"repo":"group/name",
 "pattern":"review",
 "max_lines_per_file":2}

    先看每个文件的少量命中片段；只需要路径时才选 output: files

    02 · 匹配多个候选词

    search
{"repo":"group/name",
 "pattern":"review|approval",
 "ignore_case":true,
 "paths":["knowledge"],
 "max_lines_per_file":2}

    等同 rg -i 'review|approval' knowledge，返回命中任一候选词的行

    03 · 批量读取已知范围

    read_many
{"repo":"group/name",
 "revision":"<commit>",
 "files":[
  {"path":"a.ts","start_line":20,"end_line":60},
  {"path":"b.ts","start_line":1,"end_line":40}
 ]}

    逐项检查结果；需要剩余内容时，在同一 commit 从 NextStartLine 继续读
