# Support

Choose the channel that matches the request:

- Read the [Source Graph documentation](https://context4ai.org/context/pages/e1ce6ff3105ae09d13eec7cbe39ae133.html)
  and the [reference docs](docs/README.md) in this repository.
- Use [GitHub Discussions](https://github.com/context4ai/sourcegraph/discussions)
  for usage, deployment and integration questions.
- Open an [Issue](https://github.com/context4ai/sourcegraph/issues/new) for
  reproducible defects.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

When asking for help, include the commit or image you run, the database and
topology, the surface you used (browser, HTTP, MCP or CLI), the request and
sanitized logs. Do not publish credentials, OAuth secrets, API tokens or the
contents of private repositories.
